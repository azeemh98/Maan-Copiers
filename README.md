# MAAN COPIERS — Stock & Business Manager

A single-file web app for MAAN COPIERS print shop: stock/material tracking, walk-in job tickets with thermal-printer slips, sales/purchase invoicing, party ledgers, payments, and reports. Backed by Supabase.

Open `index.html` (or `StockManagement.html`, identical) in a browser, or visit the deployed site.
